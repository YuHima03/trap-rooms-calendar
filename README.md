# traP Rooms Calendar

## Runtime Environment

This project requires the following runtime environments:

- Node.js 26.x
- pnpm 12.x
- .NET 10.x

You can use [mise](https://mise.jdx.dev/) to automatically set up `node` and `pnpm` for this project. Just run the following command in the project root directory:

```bash
mise install
```
